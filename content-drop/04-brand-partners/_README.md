# 04-brand-partners/

Logos for the scrolling client wall on the homepage.

## Two acceptable options

### Option A — logo files (preferred)

- **Format**: SVG (best) or PNG with transparent background
- **Color**: white or single-color (logos display on a black background)
- **Filename**: brand name, lowercase, hyphens. Example: `aura.svg`, `maison-rouge.svg`
- **Count**: 10–14 ideal, 6+ minimum

### Option B — text wordmarks only

If you don't have rights to use the actual logos (or they take too long to source),
just list the brand names in `COPY.md` section 7. The site renders them as
large typographic wordmarks — that's what's there now and it looks intentional.
