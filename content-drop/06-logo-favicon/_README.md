# 06-logo-favicon/

Brand mark files. Both are optional — the site has the existing logo in place.
Only drop here if you have higher-resolution versions.

| File | Spec | Used for |
|---|---|---|
| `logo.png` or `logo.svg` | Horizontal wordmark, white on transparent, ≥ 400px wide | Site header and footer |
| `favicon.png` | Square 512×512, the icon mark only (no wordmark), transparent or solid background | Browser tab, bookmarks, OS shortcuts |

## Notes

- If you only have a colour version of the logo, drop it — I can extract a
  monochrome white version for the dark UI.
- SVG is always preferred for the logo (scales crisply at any size).
- The favicon should be just the icon/mark, not the full wordmark, so it reads
  at 16×16 in a browser tab.
