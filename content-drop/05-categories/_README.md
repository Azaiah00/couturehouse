# 05-categories/

One portrait image per industry category for the "Expertise Across Categories"
horizontal scroller on the homepage.

## Spec

- **Aspect**: 3:4 portrait (e.g. 900×1200)
- **Size**: ≥ 1200px tall
- **Format**: jpg or png

## How to match images to categories

The category list itself lives in `COPY.md` section 6. Name each image after
the category, lowercase, hyphens:

```
beauty-personal-care.jpg
fashion-apparel.jpg
home-lifestyle.jpg
wellness.jpg
food-beverage.jpg
hospitality.jpg
consumer-tech.jpg
sport-performance.jpg
spirits-wine.jpg
entertainment.jpg
creators-talent.jpg
direct-to-consumer.jpg
```

(Those filenames match the placeholder category list. If you change the list
in COPY.md, rename to match.)

## Count

12 ideal. 6+ minimum (I'll surface fewer cards if you have less ready). You can
add more later.

## What looks good

- A clear hero subject from that category — a model, a product, a setting
- High contrast, editorial style
- Avoid: text in image, busy backgrounds, watermarks
